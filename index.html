English

BiRead shows every paragraph of an article next to its translation, so you can read the original and check the translation without losing your place. It is designed for iPhone Duo: unfold it and the original and the translation sit on either side of the fold.

Translation doesn't start, or asks to download languages

By default BiRead uses Apple's on-device translation. The first time you translate a language pair, iOS asks to download the language packs; allow it and translation starts once the download finishes.

"On-device translation doesn't support …"

Apple's on-device translation covers only some language pairs. For other pairs, add an AI endpoint: Settings (gear button) → AI endpoints → Add endpoint, pick your provider (or Custom), enter your API key, fetch or type a model name, and tap Test connection. Any service compatible with the OpenAI API works, including a local model on your network.

Changing the translation language

Settings → Translation language sets the default for new articles. While reading, tap the sparkles button (✨) → Translate into to change it for the current article.

Where are my articles and API keys stored?

Only on your device. Articles and translations are stored in the app; API keys are stored in the iOS Keychain. BiRead has no account and collects no data. See the privacy policy.

Reading on iPhone Duo

Unfold the device to read the original and the translation side by side. Half-fold it like a book and each column stays clear of the fold. When you fold or unfold, BiRead keeps your place and briefly highlights the paragraph you were reading.

中文

对照读把文章的每一段原文和它的译文并排放在一起，读原文时随时能看到对应的译文。它为 iPhone Duo 设计：展开阅读时，原文和译文分在折痕两侧。

没有开始翻译，或者提示下载语言

对照读默认使用 iPhone 自带的离线翻译。第一次翻译某个语言组合时，系统会提示下载语言包，允许下载，下载完成后就会开始翻译。

提示"系统翻译不支持……"

系统翻译只支持部分语言组合。其他组合可以添加 AI 端点：设置（齿轮按钮）→ AI 端点 → 添加端点，选择服务商（或"自定义"），填入你的 API Key，获取或填写模型名称，再点"测试连接"。兼容 OpenAI 接口的服务都可以用，包括局域网里的本地模型。

更改译文语言

设置 → 译文语言，决定新文章默认翻译成什么语言。阅读时点 ✨ 按钮 → 译成，可以更改当前这篇文章的译文语言。

文章和 API Key 存在哪里？

只存在你的设备上。文章和译文保存在 App 里，API Key 保存在系统钥匙串里。对照读没有账号，不收集任何数据，详见隐私政策。

在 iPhone Duo 上阅读

展开设备，原文和译文左右并排。像书一样半折时，两栏分别在折痕两侧。合上或展开时，对照读会保持你的阅读位置，并短暂高亮你正在读的那一段。
